# Architecture

```text
React/Vite frontend
        |
        v
FastAPI REST API
   |       |       |
   v       v       v
PostGIS  ML model  Weather/alert/routing adapters
```

The backend owns prediction, spatial queries, shelter scoring, and route
selection. The frontend is a presentation and interaction layer; it never
receives provider secrets. Provider integrations are adapters so a demo source
can be replaced by an official feed or routing provider without changing the
citizen workflow.

## Data labels

- **LIVE**: returned by a configured external provider.
- **LATEST AVAILABLE**: cached provider data with its original timestamp.
- **PREDICTED**: generated by the trained model.
- **DEMO / SIMULATED**: local development data and never an emergency alert.
